# Purbeli – Flavour on Wheels (website preview)

Preview of the customer website for Purbeli, Nepalese street food at 33 Glenroy Road, Glenroy VIC 3046.

Pages: Home (`index.html`), Menu, Cart, Pickup checkout and Order status.

This is a **design preview**: menu, prices and cart work in the browser, but there is no backend yet —
orders aren't sent anywhere and no payment is taken. Checkout and order status show sample data.

## Publish with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
The site appears at `https://<your-username>.github.io/purbeli-website/` after a minute or two.

## Files
- `*.html` – one file per page
- `img/` – dish photos, logo and drink illustrations
- `js/dc-lite.js` – small renderer that runs the page templates
- `js/morphdom.min.js` – [morphdom](https://github.com/patrick-steele-idem/morphdom) (MIT, see `js/morphdom.LICENSE.txt`)
